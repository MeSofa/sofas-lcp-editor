Custom Tags tags.json

Only needed if your equipment uses a tag that isn't in the Lancer core data. The core tags (Accurate, Loading, Reliable X, …) are already in the tag picker on weapons and systems — you don't define those here.

Will a custom tag drive automation? — read this

Short answer: no, not on its own. Both COMP/CON and Foundry only automate a fixed, hard-coded list of tag ids (Accurate, Inaccurate, AP, Overkill, Reliable, Loading, Limited, Knockback, Heat (Self), Smart, Seeking, Thrown, Overshield, Recharge, AI, …). A brand-new id like tg_myco_unreliable gets its name and description shown everywhere (with {VAL} filled in), but no dice are rolled for it.

So a "deal X damage only on a miss" tag would just be flavour text. The mechanically-automated ways to express that are: the Reliable X core tag (Foundry rolls it on a miss), the weapon's on-miss field (shown, not rolled), a damage entry with a save, or a bonus. Use a custom tag when you want a reusable, named piece of rules text — not for automation.

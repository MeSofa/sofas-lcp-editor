# Sofa's LCP Editor

A browser tool for building Lancer Content Packs (`.lcp` files) for
[COMP/CON](https://compcon.app). Fill in the forms, hit export, get a `.lcp` you
can install in the Content Pack Manager.

It aims to cover everything the official
[`cc-lcp-editor`](https://github.com/massif-press/cc-lcp-editor) does, with
per-field help text and full NPC support, in a single static HTML file.

## Running it

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8777
```

Vue and JSZip load from a CDN; everything else is inline. No build step.

## What it covers

**Licensed data** — manufacturers, frames (traits + core system), weapons,
systems, weapon mods.
**Pilot data** — CORE bonuses, talents, skill triggers, backgrounds, reserves,
pilot gear, bonds.
**NPC data** — classes (tiered stats), templates, features (trait / system /
reaction / tech / weapon), factions.
**Other** — environments, SITREPs, statuses & conditions, rollable tables, name
lists, custom stats, custom tags.
**Reference** — base actions, glossary entries, rules-constant overrides.

Weapons, systems, traits, core systems and most pilot items carry the shared
builders: actions, bonuses, synergies, counters and deployables. The tag and
bonus pickers show the real rules text so you know what each one does. Every
field has a hover tooltip.

Export produces a flat `.lcp` zip with live validation (required fields, unique
ids, source/license cross-references). Import reads an existing `.lcp` back in;
fields the UI doesn't cover yet round-trip untouched.

`examples/` has a small sample pack generated by the editor.

The Home-screen background feed is per-theme text — `chatter/<theme>.txt`, one
line per line, `#` lines and blanks ignored. Add a theme by adding an entry to
`THEME_LIST` in `index.html`, a matching `#lcp-forge[data-theme]` CSS block, a
`GLYPHS` entry, and a `chatter/<id>.txt` file.

The Home feed accepts `[[double brackets]]` around a word to render it with a
faint glitch.

## Not yet supported

Weapon profiles and ammo lists, integrated / special-equipment selectors, the
richer Active Effects objects, license-collection bundles, Eidolons. Fields on
categories that *are* covered round-trip untouched on import; an entirely
unknown file is dropped on re-export.

## Schema

<https://github.com/massif-press/lancer-data/wiki> is the source of truth for
the `.lcp` format; it shifts between COMP/CON releases.
